# StockMetrics

**Best Performing Stocks Dashboard**

A professional stock performance monitor that tracks top movers across **Global**, **Africa**, and **Nigeria** markets.

## Features

- Region tabs: Global | Africa | Nigeria
- Ranked by percentage performance
- Real-time style metrics (price, % change, volume)
- Mini sparkline charts on every stock
- Smart Recommendations engine
- Gainers-only filter
- Search by symbol or company name
- Clean dark finance UI

## Tech Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Zustand
- Recharts
- date-fns
- Lucide React
